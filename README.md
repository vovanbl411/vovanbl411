## 🐧 About me

I work with **Linux infrastructure and automation**, with a particular interest in understanding how systems behave under the hood rather than treating them as black boxes.

A large part of my personal engineering work revolves around **Gentoo Linux**, infrastructure automation, packaging, Wayland and building reproducible systems that are easy to inspect and maintain.

I prefer:

- simple and reproducible solutions;
- infrastructure defined as code;
- explicit and reviewable automation;
- documentation that reflects the actual state of a system;
- understanding *why* something works, not only *how* to make it work.
